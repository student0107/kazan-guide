# Фото для блока приветствия

На главной — три снимка подряд. Пока файлов нет, вместо них терракотовый градиент: сайт работает, битой картинки не будет.

Положите в эту папку **ровно три** файла JPEG:

| Файл | Что на снимке |
| --- | --- |
| `slide-1.jpg` | Мечеть Кул-Шариф |
| `slide-2.jpg` | Башня Кремля |
| `slide-3.jpg` | Кремль снаружи |

Имена именно такие. Старое имя `kazan.jpg` больше не используется.

## Размер

- Ширина около **1400–1600 px** (не 4K).
- Каждый файл желательно **до ~400 KB**.
- Формат JPEG, среднее качество.
- Эти файлы в репозиторий не кладём: они тяжёлые. Локально или на сервере — можно.
