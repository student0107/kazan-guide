# Smoke-test после деплоя на Vercel

1. Открыть главную — карта Казани, маркеры, фильтры.
2. Добавить 2–3 точки в маршрут — оранжевая линия между ними.
3. `/login` — регистрация нового email + пароль (≥6 символов).
4. На главной в чате: «где поесть» — ответ на русском, подсветка кафе на карте.
5. `/history` — появилась сессия; клик открывает диалог на главной (`?session=...`).
6. Выйти и убедиться, что чат просит войти снова.

Если чат возвращает 502 — проверьте `POLZA_API_KEY` и баланс polza.ai.
